# MacroGpt
 Prompt ChatGPT to get the protein and calories of a described food

**requires an OPENAI key and an IMGUR api key to use**

also checkout the [website version](https://github.com/lliamsymonds04/macro-ai)

## Downloading
* Python 3.12 or higher
* download the code base
* setup environment variables as shown in `.env.example`
* run `pip install -r requirements.txt`

## Usage
* run **Main.py** in the terminal and follow prompts
* select either image or text mode
* get the macros of food
